RESTORE ON THIS OR ANOTHER WINDOWS PC
-------------------------------------

1. Extract the backup folder.

2. Install Node.js if it is not already installed.

3. Install Python 3.12 if it is not already installed.

4. Open Command Prompt inside the SIHAG AI STUDIO folder.

5. Install frontend dependencies:
   npm.cmd install

6. Build the production frontend:
   npm.cmd run build

7. Start the backend once:
   backend\run_backend.bat

   On the first run, it will recreate backend\.venv
   and install the Python requirements.

8. Start SIHAG AI STUDIO:
   launch_sihag_studio.bat

9. Open in browser if it does not open automatically:
   http://localhost:3000

10. To stop both services:
    stop_sihag_studio.bat
